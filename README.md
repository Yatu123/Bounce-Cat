# Bounce-Back-to-Daylight
A platformer game made in Godot where users are a cat and have to bounce a ball to hit a lever for a ladder to appear to go to the next level.

# Features
- WASD + Arrows keys to move cat
- Ball that bounces
- Lever that shifts when hit by ball
- Climbable ladder that appears when lever shifts
  
# Built with
- Godot
- GS script

AI was used to learn the GS script syntax for Godot.
